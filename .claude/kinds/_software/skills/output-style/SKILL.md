# Output style

The failure this prevents: ignoring the owner's output-style rule until told
off.

## Rules

1. Before your first reply, read `docs/design/output-style.md`.
2. Apply every rule in it from your first reply, in every reply, including
   reports, questions and summaries.
3. If the file is absent, say so once, in one line: `No docs/design/output-style.md; using default style.`
   Do not repeat it.
4. If a rule conflicts with a format another instruction asks for, follow the
   owner's rule and say which one you followed.
5. Never wait for the owner to remind you. A reminder means the rule was
   already broken.
